Built for operators who want control

Keep the Moderations client contract; choose where inference runs. Rotate keys, tune thresholds, ship with Docker.

⇄

Drop-in API surface

/v1/moderations, /v1/models, health & readiness — OpenAI-style errors and responses.

☁

Cloud or self-hosted

Defaults to Ollama Cloud (ollama.com). Point OLLAMA_BASE_URL at a private host when you need air-gapped inference.

⟳

Multi-key pool

Round-robin across OLLAMA_API_KEYS. Cooldown on 401 / 403 / 429 / quota so one bad key doesn’t stall traffic.

☰

Policy you can edit

YAML thresholds per category plus uncertain_mode: flag, allow, or error near the boundary.

⏹

Fail-closed

Provider or parse failures return 502 / 503 / 504. The gateway never invents a clean flagged=false.

▣

Ops-ready MVP

FastAPI, Docker Compose, log redaction, constant-time API key compare, pytest with mocked Ollama.

How it works

A thin, honest pipeline — general chat models + structured JSON, then your thresholds.

1

Client calls Moderations

Your app (or OpenAI SDK) posts to the gateway with a model alias like moderation-fast.

2

Gateway talks to Ollama

Native POST /api/chat with JSON Schema structured output. Keys rotate; cooldowns apply on auth/rate failures.

3

Scores meet policy

Heuristic category scores (0–1) are compared to configs/policy.yaml. Uncertain cases follow your configured mode.

Model aliases

Client model Ollama model Notes
moderation-fast gpt-oss:20b Default path
moderation-standard gemma4:31b Heavier reasoning budget
moderation-accurate gpt-oss:120b Largest; needs serious resources self-hosted
omni-moderation-latest gpt-oss:20b Compatibility alias only — not OpenAI parity

Get running in minutes

Placeholder keys in docs are for local smoke only. Never commit real secrets.

Local (dev)

git clone https://github.com/AaronYang0628/ollama-moderation-gateway.git
cd ollama-moderation-gateway
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
export APP_ENV=development
export MODERATION_API_KEY=local-moderation-key
uvicorn app.main:app --host 0.0.0.0 --port 8000

curl

curl http://localhost:8000/v1/moderations \
  -H 'Authorization: Bearer local-moderation-key' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "moderation-fast",
    "input": "Text to screen"
  }'

Used with sub2api

Real-world wiring: point sub2api content audit (风控中心 · 内容审计) at this gateway as an OpenAI-compatible Moderations backend — same /v1/moderations contract, your own Ollama-backed scoring.

Why it fits. sub2api expects an OpenAI-style moderations base. This gateway speaks that dialect, so you can keep sub2api’s risk-control UI while inference runs through Ollama Cloud or your own host — without inventing a custom client.

Verified config tips

1

Base URL — no trailing /v1

Set Base URL to https://ollama-moderation-gateway.onrender.com without /v1. sub2api appends /v1/moderations itself; including /v1 produces /v1/v1/... and {"detail":"Not Found"}.

2

Model

Use moderation-fast (or the omni-moderation-latest compatibility alias).

3

API Key = gateway key

Paste the gateway’s MODERATION_API_KEY, not an Ollama Cloud key. Docs use your-gateway-api-key as a placeholder — the public demo may require your own deploy key.

4

Raise timeout_ms to 30000

Default 3000 is too short for cloud LLM latency plus Render cold start. Set timeout_ms to 30000 (30s).

Reminder: scores are heuristic risk estimates from general chat models — not equivalent to OpenAI omni-moderation-latest. Evaluate on your traffic before relying on it in production.

Integration reference: github.com/Wei-Shaw/sub2api. This page documents only this verified pairing — not a catalog of other products.

Important: not equivalent to OpenAI omni-moderation

Scoring uses general-purpose chat models, not dedicated safety classifiers.

  • category_scores are heuristic risk estimates (0–1), not calibrated probabilities.
  • Quality, score scale, and behavior differ from OpenAI omni-moderation-latest.
  • Evaluate on your languages and risk profile before production (scripts/evaluate.py).
